## Purpose

通过本地浏览器页面让用户可视化配置和运行采集分析工作流，使用可编辑节点画布直观组织来源、分析和汇聚，并查看运行结果、评估和会话以完成日常使用闭环。

## ADDED Requirements

### Requirement: 完整浏览器管理

前端 SHALL 支持 Workflow 列表、配置保存、运行触发、session/备份查看、资源编辑、评估比较及会话，真实调用 API 并显示验证错误。

#### Scenario: 保存并运行

- **WHEN** 用户编辑配置并点击运行
- **THEN** 保存有效定义后显示真实 session 状态及结果

#### Scenario: 错误输入

- **WHEN** API 返回字段验证失败
- **THEN** 页面保留输入并展示原因，不显示虚假成功

### Requirement: 画布编排

前端 SHALL 提供可移动的来源、分析、汇聚和通知节点及连接关系，支持增删配置并导入导出 JSON，保存后的布局可重新打开。

#### Scenario: 编辑依赖

- **WHEN** 用户在画布上改变分支来源
- **THEN** 保存后该分支使用对应来源子集，节点连线与定义一致

#### Scenario: 响应式交互

- **WHEN** 用户在窄屏或键盘模式访问页面
- **THEN** 主要操作和信息可访问，任务进度与错误不只通过颜色表达
