| 决策 | 依据 |
| --- | --- |
| 模型发现不缓存、每次点击发起 | 原清单明确要求每次点击模型输入框异步请求 `/v1/models` |
| 未保存配置可发现 | 原实现仅支持已保存配置，是该问题的根因；`AIService.list_models` 接收完整 `AIConfig` 快照 |

| 默认模型可用才跳过对话框 | `/agents/models` 是当前可用目录；本地保存的引用可能已失效 |
| 思考默认折叠 | 原清单明确要求，现有 `agentDisplay.ts` 使用 `false` 作为缺省读取值 |
