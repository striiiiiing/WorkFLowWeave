# Agent 前端设计

本文件是 [Agent 设计](design.md) 的前端分解；API 与执行状态以主设计为准。复用当前 Vue 3、Element Plus、Tailwind、Vue Router 和局部组合式状态，不为聊天重新引入 Pinia。

## 1. 入口与布局

导航增加一个「Agent」，路由为 `/agents` 与 `/agents/:sessionId`。会话列表不混入 Workflow 的运行记录；Agent 会话可以包含多轮消息，每轮执行有独立 turn_id。

桌面采用两栏加按需抽屉：左侧可折叠会话列表，中央聊天区域，点击工具或文件后打开右侧详情。避免同时常驻三个复杂面板。窄屏只保留聊天，会话、文件和设置各用抽屉。

```text
┌──────────────┬────────────────────────────────────────────┐
│ ＋ 新会话     │ 日志排查        模型 ▾   文件   设置       │
│              │ 沙箱已开启      上下文 42%                 │
│ 今天         ├────────────────────────────────────────────┤
│ · 日志排查   │ 用户：看看今天的异常日志                     │
│ · 昨日汇总   │                                            │
│              │ ▸ 正在读取日志 / 共 3 个读取任务             │
│              │ ▸ 采集完成 · 23 条记录 · 查看结果            │
│              │ Agent：主要异常集中在……                     │
│              │                                            │
│              │ ── 已压缩早期上下文 · 查看摘要 ──            │
│              ├────────────────────────────────────────────┤
│              │ 输入消息…                       发送 / 停止 │
└──────────────┴────────────────────────────────────────────┘
```

会话列表显示标题、最后活动时间和运行/中断/失败状态；不展示内部节点名或 checkpoint ID。新会话复用最近选择的已配置 AI 提供方与模型；没有可用模型时直接引导去现有资源页配置，不猜测默认模型。

## 2. 对话与工具

- 助手消息流式展示，沿用现有 Markdown 渲染基础；禁用 HTML，过滤危险链接协议。流中间态节流渲染，完成后再进行完整 Markdown 渲染。
- 工具卡片默认只显示动作、人类可读目标、排队/运行/完成/失败、耗时和简短结果。Schema、参数 JSON、完整错误放在展开区，不把机器 DTO 铺在对话中。
- 并行读取卡片可分组；写操作显示「等待其他操作完成」或「执行中」。后端负责互斥，前端不根据工具名称推断执行类别。
- 日志与采集结果优先复用已有报告块、指标、表格；完整正文通过文件抽屉分页读取。原始 JSON 始终可展开，不建立另一个 Agent 专属报告 Schema。
- 渠道卡片明确展示目标和实际回执；`delivery_uncertain` 显示「可能已发送，结果未知」，不提供自动重发。
- 停止按钮发取消请求，收到终态后才显示停止完成。停止不会把已经完成的文件写入或渠道发送显示成撤销。
- 一轮运行时可继续编辑输入草稿，发送按钮暂不可用；后端并发提交返回 `409 turn_active`。首版不做后台消息队列或运行中插入新指令。

## 3. 文件抽屉

文件入口提供四组位置：`AGENTS.md`、`Memory/`、`History/`、`Artifacts/`，另有只读 `Catalog/` 能力目录。

| 内容 | 展示与编辑 |
| --- | --- |
| `AGENTS.md` | 普通文本编辑；保存后提示「下一次模型请求生效」；展示其上下文占用。 |
| `Memory/YYYY-MM-DD.md` | 按日期列出；Agent 与用户通过同一文件写入边界修改。 |
| `History/<sessionId>.md` | Agent 可编辑的历史笔记，不要求固定模板。 |
| `History/<sessionId>/events.jsonl`、`summaries/` | 运行记录和压缩摘要，默认可读；与可编辑历史笔记区分标识。 |
| `Artifacts/` | 工具完整输出，按调用关联，默认只读、分页查看。 |
| `Catalog/` | 从插件注册结果生成的说明和 Schema，只读，不作为配置入口。 |

编辑使用现有等宽文本输入/JSON 查看风格，不引入 IDE。文件 GET 返回 `etag`，保存携带 `If-Match`；发现 Agent 已经改写时展示冲突并保留用户草稿，不静默覆盖。运行中保存也必须经过后端相同的写锁。这个版本条件仅用于新增 Agent 文件 API，不改现有资源编辑的保存语义。

历史运行消息来自事实记录，不解析 Agent 写的历史笔记来伪造工具状态。文件不存在、已删除、输出被截断均明确展示。

## 4. 设置

会话顶部设置抽屉只保留必要配置：

1. 已配置的 AI 提供方、模型；高级区显示上下文容量、输出预留和压缩配置。
2. 工具插件开关：插件网关、文件读取、文件写入、文本搜索、Shell。显示当前实际可用的工具数量；关闭后下一轮不再注册。
3. 沙箱开关和 Shell 网络开关；显示「沙箱开启」「沙箱关闭」或「沙箱不可用」，不可把启动失败展示成关闭后可继续。
4. 工作目录和每日记忆日期使用的时区；首版工作目录由服务管理，只展示路径，不给模型提供修改宿主路径的入口。

插件开关实际粒度是插件包：默认将 read/write/grep/shell 分别打包，因而可以逐项关闭；第三方包注册多个工具时随包启停。配置编辑沿用显式保存，运行中的一轮固定原配置。目录与插件开关不是重复资源配置；账号、来源和渠道仍去现有资源页面管理。

沙箱关闭时用一条简短说明表达其含义：「Shell 按服务进程权限访问主机」。不增加逐次弹窗审批。关闭文件写入工具后说明 Agent 不能再通过该工具保存记忆；如果 Shell 仍开启，其写文件能力仍然存在，不能把插件关闭描述成安全权限隔离。

## 5. 上下文与断线

- 顶部显示已用输入预算、百分比，以及「估算」或「上次请求实际值」；不伪造精确 Token 数。
- 压缩只产生一条轻量系统事件，可展开查看摘要和对应历史范围；不会删除聊天 UI 中的旧消息。
- 提供「压缩上下文」动作，走管理 API，不给模型增加 compact 工具。压缩中仍可停止。
- SSE 断线显示「连接中断，正在重连」，从最近 event_id 续传；重复事件按 ID 去重，流断开不会自动取消后台运行。
- 续传失败或服务重启导致运行中断时，显示确定状态和错误；用户可以在已有会话发新消息继续。首版不提供会重新执行未确认副作用的「原地重跑」按钮。

## 6. 组件与代码位置

| 拟新增/修改位置 | 职责 |
| --- | --- |
| `frontend/src/views/AgentView.vue` | 组合会话列表、对话、输入与抽屉。 |
| `frontend/src/components/agent/AgentTranscript.vue` | 消息列表和压缩分隔提示。 |
| `frontend/src/components/agent/AgentToolCall.vue` | 调用卡片；复用报告组件。 |
| `frontend/src/components/agent/AgentFileDrawer.vue` | 文件树、分页读取与显式保存。 |
| `frontend/src/components/agent/AgentSettings.vue` | 模型、工具与沙箱设置。 |
| `frontend/src/composables/useAgentStream.ts` | SSE 生命周期、续传游标与去重；退出路由关闭连接。 |
| `frontend/src/api/agents.ts` | 主设计列出的 Agent HTTP 契约。 |
| `frontend/src/router/{index,navigation}.ts` | 两个路由和单个导航入口。 |

会话列表、文件元数据复用 `useQuery`，发送/停止/保存复用 `useAsyncTask`，通用框架复用 PageHeader、SectionCard、AppIcon、StatusBadge。Schema 展示与参数预览使用 `ParameterField` 及现有 schemaValidation；不重复实现 JSON Schema 验证。

## 7. 前端验收

用本地 mock 采集器覆盖：发消息 → 流式文本 → 并行采集卡片 → 完成；再覆盖写入排队、Shell 关闭、沙箱不可用、压缩后历史保留、SSE 续传去重、停止、文件修改冲突和手机布局。类型检查与构建通过后执行真实本地后端浏览器烟测；测试数据使用临时工作目录，不连接真实渠道或发送邮件。
