## 关键取舍及默认值依据

| 决策/默认值 | 依据和理由 |
| --- | --- |
| create_agent + LangGraph + SummarizationMiddleware | 用户明确要求 LangGraph 并尽量复用现成能力；官方工厂内部已有 Send/工具循环。当前版本不满足 middleware 依赖，先做成组升级验证。 |
| 5 个默认工具 | plugin 聚合所有 collector/channel；read 合并目录，grep 合并文件搜索，write 合并创建/追加/精确替换；满足需求且不引入专用记忆工具。 |
| 单个 Agent 工作区，多会话，每会话 1 个活动轮 | 用户需要记忆延续，没有多租户/多 Agent 需求；同会话不同时更新消息状态。 |
| 读取并发 4，写并发 1 | 4 参考现有 Workflow collection_concurrency；1 来自用户「写只能单个」，所有 Agent 会话共享，写与读也互斥。 |
| 未声明执行类别的 Collector 为 exclusive | 现有 Collector 协议不保证只读；明确声明才放进读并发，避免按插件名称猜测副作用。此默认只影响新 Agent 调度。 |
| 首次配置的五工具插件均启用；可逐个关闭 | 用户要求基础读写/grep/Shell，同时要求额外工具可关；首版不强制用户经过另一层启用仪式，启停只存现有插件配置。 |
| sandbox.enabled=true，sandbox.network=false | 用户要求简单可关沙箱；以工作区操作为默认范围，采集/搜索主要通过既有插件，Shell 无需默认联网。关闭后明确宿主权限执行。 |
| 每工具预览约 2,000 tokens | 采集服务通常只需短结果/计数/证据引用；正文在文件按需读取。可配置，没有把它当模型上下文上限。 |
| 单次输出上限 16 MiB | 参考现有 logs 允许的最大读取量级，防止 Shell 无限输出；达到上限明确错误并保留部分输出，不静默截断为成功。 |
| read 默认最多 200 行，仍受预览 token 上限约束 | 与项目日志默认 200 行的阅读规模一致；降低第一次读取的上下文成本。支持 offset 分页，无须一次读全文。 |
| plugin.list 默认 20 项，支持 query/cursor | 只返回短能力目录；避免插件规模增长时一次塞入上下文。20 是目录分页建议，不是框架消息保留上限。 |
| grep 默认最多 50 条命中，仍受预览预算约束 | 一轮调查通常先定位少数文件和行号；更多结果分页或收窄 query。命中截断必须可见。 |
| Shell 单次默认 60 秒，可配置 | 对齐现有 SourceConfig 的单次调用量级；用户可增加预算，无后台执行/poll 工具。Collector/Channel 继续取实例 timeout。 |
| 模型总 timeout 复用 AIConfig；流式无活动默认 300 秒 | 当前 AIConfig 默认 600 秒；300 秒用于发现持续无事件，属于可调整的体验阈值，不假定长推理模型绝不会超过该时间。 |
| C 未知时显式配置；R 与真实输出上限一致 | 兼容渠道 `/models` 未承诺上下文元信息；不能猜 8k/16k，或以 UI 填值替代实际请求限制。 |
| 安全余量 5%C，触发 80%B，保留 20%B | 为估算误差、工具结果与下次回复留余量；是本设计建议，所有比例可配置并验证有效范围。 |
| 摘要上限 min(4096, 5%B)；摘要模型默认当前模型 | 足够保存目标/约束/引用而非长正文；可以提高，避免强制第二个模型配置或默认切换更贵模型。 |
| trim_tokens_to_summarize=None | 官方默认 4000 tokens 会在摘要前裁掉内容，且裁剪异常有隐式 15 条 fallback；使用官方关闭裁剪选项，完整输入先经过摘要模型容量检查。 |
| 每次主模型请求前最多一次逻辑压缩 | 防止一个大文件造成循环压缩；摘要模型自身瞬时错误重试与逻辑重复压缩分开计算。失败不发布新摘要。 |
| 时区 UTC，允许 Asia/Shanghai 等 IANA 名称 | 服务不能依赖不同宿主的隐式本地时区；用户可按日常所在地设置。不存在必须用服务器当天日期的隐藏约定。 |
| 不自动重试工具，不自动重放中断副作用 | Manager 已有 delivery_uncertain 契约；写入、Shell 和渠道都可能在结果落盘前完成。保留未知结果而非假装恰好一次。 |
| 事件 JSONL + 官方 checkpoint；不增加业务正文数据库 | 满足文件可读；checkpoint 用于框架执行恢复，文件保存事实和可编辑笔记，各自职责清楚。 |

上述分页/超时/输出数值集中进入一份 Agent/工具配置模型，不散落为各插件不同常量。启动验证正数和比例关系；不额外引入硬性 Token 上限。AGENTS 太大、摘要模型窗口不足等情况按照设计明确报错。
