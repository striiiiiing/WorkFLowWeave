## ADDED Requirements

### Requirement: Workflow 与 Agent 共用 MCP 基础能力

系统 SHALL 为 Workflow 采集、来源配置视图和 Agent 提供同一套 MCP 服务配置解析、工具目录、schema 查询、认证解析、连接生命周期和原始工具调用能力。调用方 SHALL 传入明确的服务范围、调用参数和执行上下文。共享层 SHALL 不包含 Workflow 字段处理、格式转换或输入限额，也不替 Agent 选择工具。共享能力 SHALL 不要求不同运行强制复用同一个有状态协议会话；连接复用必须保持服务配置、认证和会话状态的隔离。

#### Scenario: 两类调用使用同一服务定义

- **WHEN** Workflow 和其接续 Agent 调用同一配置版本的 MCP 服务
- **THEN** 两者使用同一服务定义、工具身份和协议调用规则，分别保留各自调用上下文；Workflow 的输入处理配置不会进入共享调用层

### Requirement: MCP 服务与工具具有明确身份

系统 SHALL 以稳定服务标识及原始工具名共同确定工具，不仅靠拼接后的展示名路由。服务连接定义与采集项调用参数 SHALL 分开存储。运行快照 SHALL 绑定所用服务定义或可恢复的配置版本及凭据引用，不将凭据明文注入模型。范围内服务缺失、停用或绑定版本不可用时 SHALL 明确报错，不改用同名新配置或全局其他服务。

#### Scenario: 两个服务有同名工具

- **WHEN** 两个 MCP 服务都声明名为 `search` 的工具
- **THEN** 目录、schema 查询和实际调用均能按服务身份区分，不因展示名归一化而调用错误服务

#### Scenario: 服务配置在运行后被替换

- **WHEN** Agent 接续旧 Workflow，但该运行绑定的服务配置已无法恢复
- **THEN** 系统报告对应服务不可用，不把同名的新服务当成原服务调用

### Requirement: 工具元数据缓存与按需连接

系统 SHALL 采用按需连接，创建 Workflow 或 Agent 上下文本身不启动全部 MCP 服务。目录和 schema SHALL 能从匹配服务配置版本的元数据缓存读取；缓存只保存工具元数据，不作为调用结果缓存。首次配置查询、显式加载某服务目录或调用工具需要连接时，系统 SHALL 只加载所需服务并获取真实目录。目录 SHALL 区分未加载、已缓存、已连接和加载失败，不把未加载或连接失败呈现为空目录。

#### Scenario: 使用已有目录缓存

- **WHEN** Agent 查询某个已有有效元数据缓存但未连接的服务
- **THEN** 系统返回缓存目录及其状态，无须仅为查询启动该服务

#### Scenario: 冷启动时发现工具

- **WHEN** Agent 搜索时某个范围内服务尚无工具元数据
- **THEN** 搜索结果指出目录尚不完整并给出该服务标识；Agent 可按需加载该服务目录，而不是收到“没有工具”的错误结论

### Requirement: 目录更新与调用校验

系统 SHALL 在连接、重连及服务支持的工具列表变更通知后更新目录；缓存不再存在的工具 SHALL 失效。每次调用 SHALL 在实际分派前检查服务范围、工具可用性和参数 schema，不能仅在搜索阶段检查。schema 不支持或参数不合法 SHALL 明确失败，不静默跳过校验或猜测参数。schema 查询 SHALL 保留完整约束及引用关系，摘要不能作为校验依据。

#### Scenario: 缓存工具被移除

- **WHEN** Agent 从缓存发现工具，但连接后的真实目录已没有该工具
- **THEN** 系统更新目录并报告工具不可用，不按旧缓存分派，也不自动换成近似名称工具

#### Scenario: 绕过搜索直接指定工具

- **WHEN** 调用方直接提交一个不在其服务范围内的工具身份
- **THEN** 共享调用入口拒绝该调用，不因跳过目录查询而放行

### Requirement: 原始返回与执行事实可追踪

共享层 SHALL 返回原始 MCP 结果，包括 `content`、`structuredContent`、`isError` 等存在的协议字段，不将整个结果信封误当作业务 JSON，不因缺少结构化内容而制造空集合。调用事件 SHALL 能关联实际服务、工具和调用上下文。超时、取消、协议错误及工具错误 SHALL 保持区别；断线重连不等于可以重放已发送且结果未知的工具调用。

#### Scenario: 工具返回混合内容

- **WHEN** MCP 同时返回结构化内容、文本与图片内容块
- **THEN** 共享层完整保留这些内容及顺序，由 Workflow 或 Agent 各自适配可消费表示，不在共享层丢弃非文本内容或执行 token 截取

#### Scenario: 已发送调用后断线

- **WHEN** 请求已发出但连接在结果确认前中断
- **THEN** 系统报告失败或结果未知及其阶段；连接恢复不自动重放该次工具调用
