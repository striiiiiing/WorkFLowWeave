# Workflow 执行

依据：[模块设计](../../modules/workflow/design.md)、[总设计](../../design.md)。
本文件记录该活动变更的行为增量，不声明实现已经验收。

## Purpose

为固定触发的采集与分析任务提供共享输入、并行分析、可选汇总和有序通知，使用户能够按保存的定义执行一次完整流程，并在部分失败时得到明确且可解释的结果。

## ADDED Requirements

### Requirement: 共享输入与确定顺序

系统 SHALL 为一次运行固定配置快照，按来源声明顺序编排共享输入；所有分析分支接收同一份完整输入，完成先后不得改变输出顺序。

#### Scenario: 分支乱序完成

- **WHEN** 多个分析分支以不同顺序完成
- **THEN** 结果仍按配置顺序排列，且活动运行不受随后资源修改影响

### Requirement: 可选汇总和失败策略

系统 SHALL 按配置启用汇总或分别输出成功分支，并明确记录采集、分析、投递和备份状态，按所属失败策略处理异常。

#### Scenario: 关闭汇总

- **WHEN** 运行关闭汇总且存在成功分支
- **THEN** 系统分别输出成功分支，并保留失败分支诊断而不伪装为成功
