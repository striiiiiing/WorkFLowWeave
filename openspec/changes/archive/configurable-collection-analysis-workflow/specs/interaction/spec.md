# API 与命令行交互

依据：[模块设计](../../modules/interaction/design.md)、[总设计](../../design.md)。
本文件记录该活动变更的行为增量，不声明实现已经验收。

## Purpose

向用户与外部程序集成提供资源管理、运行控制及只读结果查询入口，让 API 和命令行共享同一业务语义与校验结果，避免旁路操作直接改写持久化存储或运行事实。

## ADDED Requirements

### Requirement: 统一业务入口

系统 SHALL 提供资源管理、触发、恢复、取消和查询入口；命令行通过同一 HTTP API 执行业务操作，不维护独立资源状态。

#### Scenario: 非法资源提交

- **WHEN** 用户通过 API 或命令行提交不合法配置
- **THEN** 收到一致的业务校验失败，不启动半配置运行

### Requirement: 运行查询只读

系统 SHALL 允许查询运行状态、历史版本与正文可用性，不向外提供直接写入运行存档的接口。

#### Scenario: 读取历史结果

- **WHEN** 客户端查询某个运行的固定版本
- **THEN** 取得该版本的业务视图，查询不会触发重采或恢复
