# 数据采集

依据：[模块设计](../../modules/collection/design.md)、[总设计](../../design.md)。
本文件记录该活动变更的行为增量，不声明实现已经验收。

## Purpose

为外部来源、内部历史与日志提供一致的采集行为和可解释的结果状态，使调用方能够配置来源内的筛选与编排，并区分没有内容、来源缺失以及真实执行失败。

## ADDED Requirements

### Requirement: 区分采集结果

系统 SHALL 区分成功、原始空结果、筛选后空结果、来源缺失、失败和超时；来源内部的字段选择、过滤、分组与计数遵守能力声明。

#### Scenario: 采集异常

- **WHEN** 来源执行抛出异常或超时
- **THEN** 返回明确失败或超时状态，不作为空结果处理

### Requirement: 历史读取不重采

系统 SHALL 从已保存的只读运行内容采集历史，遵守次数、时间和内容预算，不重新运行被引用的工作流或原始来源。

#### Scenario: 引用历史内容

- **WHEN** 历史来源请求一个已保存阶段的内容
- **THEN** 返回对应历史内容或明确不可用原因，不向原始来源发起请求
