# 浏览器管理界面

依据：[模块设计](../../modules/frontend/design.md)、[总设计](../../design.md)。
本文件记录该活动变更的行为增量，不声明实现已经验收。

## Purpose

为个人开发者和自托管用户提供通过后端接口管理资源与运行的浏览器界面，采用结构化配置流程，并提供适配移动设备和键盘操作的状态反馈，不在浏览器维护第二份业务事实。

## ADDED Requirements

### Requirement: 表单化编排与后端事实

界面 SHALL 通过后端 API 管理资源和运行，以流式阶梯卡片与结构化表单编排工作流，不使用节点连线画布或本地持久化作为第二业务事实来源。

#### Scenario: 编辑工作流

- **WHEN** 用户在浏览器配置来源、分析和通知步骤
- **THEN** 界面以结构化配置提交后端校验，保存状态由后端结果决定

### Requirement: 移动端与无障碍

界面 SHALL 支持最小 375px 宽度且无水平溢出，可交互按钮至少具有 44×44px 触控范围；常规内容满足 WCAG 2.1 AA，核心状态和告警满足设计规定的 AAA 对比度。

#### Scenario: 窄屏操作

- **WHEN** 用户在 375px 宽度设备查看并操作管理界面
- **THEN** 主要操作可触达，状态不只依赖颜色传达且无需水平滚动
