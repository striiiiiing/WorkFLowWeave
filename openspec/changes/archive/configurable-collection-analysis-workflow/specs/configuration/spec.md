# 配置与插件资源

依据：[模块设计](../../modules/config/design.md)、[总设计](../../design.md)。
本文件记录该活动变更的行为增量，不声明实现已经验收。

## Purpose

为可复用来源、模型、通知和工作流资源提供统一的保存及校验边界，并管理插件声明及注册结果，使运行读取完整有效的配置，错误配置不会替换已有可用资源。

## ADDED Requirements

### Requirement: 原子发布有效资源

系统 SHALL 在保存或重载资源时完整校验配置及引用，成功后原子发布有效视图；校验或写入失败保留原有效视图。

#### Scenario: 提交无效引用

- **WHEN** 候选工作流引用不存在或不合法的资源
- **THEN** 提交失败并给出诊断，已有资源和活动运行快照保持有效

### Requirement: 插件故障隔离

系统 SHALL 验证插件清单及能力声明，撤销失败插件的临时注册并报告原因，同时允许其他有效插件继续使用。

#### Scenario: 单个插件注册失败

- **WHEN** 一个插件入口导入或声明校验失败
- **THEN** 该插件不发布部分注册，其他有效插件保留

### Requirement: 实例与调用配置

系统 SHALL 区分实例连接配置和工作流调用设置，仅允许工作流覆盖能力声明允许的选项；运行固定合并后的配置。

#### Scenario: 覆盖实例专属字段

- **WHEN** 工作流尝试覆盖未声明允许覆盖的连接字段
- **THEN** 配置校验拒绝该覆盖并指出不允许的字段
