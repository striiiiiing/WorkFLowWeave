## State 与依赖决策

- 动态业务事实只通过 LangGraph state 中的 `phases`、`items`、`stopped`、`status`、`generation` 和 `retry_stage` 传递。
- CollectorManager、AIService、ChannelManager、ArchiveRuntime 等是节点构建时注入的静态能力；它们不能成为下一阶段的外部控制器。
- checkpoint 只保存控制状态和业务存档引用；正文继续由 SessionStore 按 key 读取，避免把正文或运行时依赖塞进图状态。
- intent 节点先提交管理事实，receipt 节点再产生外部副作用并保存回执；恢复时不根据业务历史猜测缺失的 checkpoint。
