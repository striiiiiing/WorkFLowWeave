## 默认值与不变量

- 前缀可选，无声明则直接随机编号；插件前缀仅允许既有 ID 字符集且最多 43 位，依据已有 ID 总长 80 与 UUID 36 位及分隔符 1 位，保证生成编号合法。自定义编号只服从既有 ID 约束，无强制前缀规则；插件切换不得覆盖用户手工编号。
- 停用不删除已保存绑定与覆盖参数；执行快照只包含启用来源及其对应覆盖。通知停用不发送；恢复启用后原有参数可直接使用。
- 保存校验包括停用项，运行时才过滤。全部来源停用时返回明确错误 `workflow_no_enabled_sources`（HTTP 409），依据 `WorkflowDefinition.sources` 至少一项的既有约束；不为绕过约束而偷偷执行已停用来源。
- 结果读取固定于同一运行版本；使用已经存档的实际结果，缺失/过期明确说明，不能取当前资源推断历史或伪造成功。默认展示正文与结构化结果，原始 JSON 仅高级模式。
- API 请求是否失败由 HTTP 状态判断。成功读取的运行或阶段记录可以携带执行错误，仍必须交给页面展示，不能被通用请求层当作查询失败而停止刷新。依据现有 `SessionRecord.error` / `PhaseContent.error` 契约及真实后端浏览器复现。
- 凭据使用专用输入框，但不删除其原有字段规则；准备加密凭据后再校验完整参数，保留邮件用户名与密码的组合约束。参数同步保留其他字段尚未通过校验的输入。
- 保持现有超时、重试、并发、备份默认值。新增插件展示配置须是可校验的声明数据，不运行插件提供的前端代码。
