## 决策与默认依据

- Cron 严格五段、默认 UTC：现有后端时间使用 UTC；前端展示时区，避免暗用机器本地时区。秒间隔不能普遍等价为 Cron，因此显式兼容，互斥校验。
- 话题名由原会话事件持久化：Agent 已用事件日志恢复状态，不创建第二数据库/浏览器命名来源。
- 思考默认折叠：用户清单明确要求；只展示实际 reasoning 数据，展示偏好不影响模型调用。
- 动画默认 150ms、最长 300ms：用户明确给出的 100–200ms 常规范围和 300ms 上限。
- 不在本任务重试失败的远端推送、不改原需求稿行尾：保留提交范围和需求证据。
- 代码由根代理独立完成；仅测试、真实浏览器和琐碎非代码工作可委派 Luna，依据用户最新纠正。

### 本轮决策依据

- Session ID 仍是可操作链接，保留 `color`、hover 和 `:focus-visible`，只去掉 `text-decoration`，避免失去可识别反馈。
- 数据源操作属于同一个表单提交入口；将启用开关与取消/保存放在表单末尾，避免标题区域同时承担上下文和提交操作，且不增加第二套保存逻辑。
- 渠道卡片复用 `SourceBindingItem` 的序号、状态标签和底部操作区视觉语言。渠道的全局资源与工作流覆盖仍由既有 `ChannelConfig`/`ChannelOverride` 契约分别拥有，未新增本地渠道配置来源。
