实现Cron相关逻辑

采用类似于openclaw的设计，

| 组件           | 职责       | 关键方法              |
| :------------- | :--------- | :-------------------- |
| **CronStore**  | 持久化存储 | load / save           |
| **CronOps**    | CRUD 操作  | add / remove / update |
| **CronTimer**  | 定时调度   | armTimer / onTimer    |
| **executeJob** | 任务执行   | main vs isolated      |

**一个定时器管所有任务**。不是给每个任务都开一个定时器

同时有三种调度类型，at 用于一次性提醒，every 用于周期性任务，cron 则支持复杂的时间表达式。

at/every/cron只是前端表现，实际上到了后端都是Cron和interval
